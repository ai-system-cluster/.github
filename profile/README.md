一支专注于将大模型能力**落地到实际业务场景**的工程团队。目前重点服务 **ETC 高速公路电子收费**行业，并向更广泛的智能服务方向扩展。

## 工程理念

- **生产优先** — 任何能力都要先解决"上线后稳定运行"再谈优化
- **可观测** — 全链路日志、置信度评分、转人工率监控
- **可迭代** — 知识库可热更新、Prompt 可灰度发布
- **数据闭环** — 用户每一次提问都沉淀为下一次的训练数据
